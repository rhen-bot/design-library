# ghostlyyy Design Library

A personal design-reference tool in development by **ghostlyyy**.

Design Library is intended to help its owner explore saved visual inspiration and use selected references with Codex to create graphics, branding, artwork and interface code.

## Intended experience

- Explore the authenticated user's saved Pins or focus on a selected Board.
- Inspect images and available animation frames for composition, color, typography, texture and motion.
- Select the aspects of each reference that matter to a creative task.
- Use a local Model Context Protocol (MCP) connector and a companion Codex skill to help create and refine designs.

The initial version is for the owner's personal use. It is designed around read-only access to authorized public Pins and Boards. Secret Boards are outside the initial scope.

## Development status

The Pinterest integration is not yet operational. API approval, personal-account access, saved-Pin coverage, media availability and permitted AI processing are being evaluated. These are intended capabilities, not claims of currently available access.

The proposed workflow may send selected reference images, animation frames and related context to OpenAI through Codex and its creation tools, subject to applicable permissions. The project does not involve training or fine-tuning models. Any live integration must match the permissions granted and the published privacy notice.

This is an independent project and is not an official Pinterest or OpenAI product.
